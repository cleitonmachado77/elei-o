# Enquetes Eleições 2028 — Abatia

Artes de Instagram Stories (1080×1920) fiéis ao modelo original **Abatia Sem Filtro**.

Cada PNG preserva o logo, as cores, a tipografia, a urna, a moldura neon e a cidade do modelo, acrescentando somente:

- círculo branco para a foto do candidato
- pergunta com o nome do candidato
- espaço branco para o sticker **Sim / Não** do Instagram

## Arquivos

- `enquetes-2028-todas.zip` — todas as 9 artes atualizadas
- `stories/enquete-*.png` — uma arte por candidato

## Como usar

1. Abra a arte no Stories.
2. Cole a foto no círculo branco.
3. Adicione o sticker Sim/Não no espaço branco abaixo da pergunta.

# Enquetes Eleições 2028 — Abatia

Artes de Instagram Stories (1080×1920) para enquete de prefeito.

Cada PNG tem:
- círculo branco para a foto do candidato
- área vazia para o sticker **Sim / Não** do Instagram

## Arquivos

- `enquetes-2028-todas.zip` — todas as 9 artes
- `stories/enquete-*.png` — uma arte por candidato

## Como usar

1. Abra a arte no Stories
2. Cole a foto no círculo branco
3. Adicione o sticker Sim/Não na área vazia
